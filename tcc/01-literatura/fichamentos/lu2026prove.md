# Bridging Probabilistic LLMs and Deterministic Statistical Validation: The PROVE Multi-Agent Framework for Clinical Trial Reporting

> **Leitura: apenas o resumo (abstract) oficial do arXiv**, lido em 29/09/2026. Não revisado por pares, salvo indicação.

## O que se sabe (do resumo)
Framework em que o LLM (opcional) interpreta a linguagem das tabelas, mas **validadores programados** são responsáveis pelas decisões numéricas e lógicas. Com rótulos variados, o casamento semântico por LLM elevou o recall de 0,588 para 0,993; decisões numéricas continuam determinísticas.

## Relação com o meu TCC
**Precedente de design para meu verificador híbrido:** LLM para interpretar variação de linguagem, código para checar números e lógica. Outro domínio (relatórios de ensaios clínicos).
